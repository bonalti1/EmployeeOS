# Rolando's Dashboard — Roadmap

Target pricing direction: consumer **$8–10/month** with a free tier (not $100).

## Phase 1 — Foundation ✅
- [x] Today home screen
- [x] Mobile nav (drawer + top bar)
- [x] Toasts + undo-on-delete + skeletons
- [x] Profile name → greeting + signature
- [x] Compact, static sidebar

## Phase 2 — Tab depth ✅
- [x] Family: per-member profiles (appts, meds, records, report cards, allergies/doctor/insurance, avatars)
- [x] Health: weight chart with goal line, goal weight/BMI, searchable records
- [x] Payments: month view, fill-row, spend chart, CSV import
- [x] Calendar: event times, click-to-edit, agenda view
- [x] Tasks: filter chips + grouping (week/month)
- [x] Home: daily non-negotiables
- [x] Journal: voice recording + live transcription + daily entries

## Phase 3 — Connected services
- [ ] Google Calendar sync
- [ ] Plaid (bank)
- [ ] Push notifications
- [ ] Apple Health / Garmin import
- [ ] Journal: cloud transcription (Whisper) + AI summaries

## Phase 4 — Productize (sellable)
- [ ] Accounts + cloud sync
- [ ] Stripe billing + free trial
- [ ] Onboarding flow
- [ ] Security/privacy + backups + error tracking
